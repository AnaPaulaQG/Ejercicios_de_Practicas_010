# Tarjeta Personal - React

Tarjeta de presentación personal desarrollada como trabajo práctico.

## Descripción

Componente `TarjetaPersonal` en React + TypeScript que muestra en la pantalla
una foto como de perfil, nombre, formacion, lugar, contacto,
usando props tipadas con `interface`.

## Cómo correrlo

npm install
npm run dev

Luego abrir http://localhost:5173/ en el navegador.

## Tecnologías utilizadas

- React
- TypeScript
- Vite
